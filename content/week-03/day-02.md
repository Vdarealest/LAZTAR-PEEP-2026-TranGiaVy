## UI Design

Today the team focused on designing the UI for the Mini-WMS system.

- Reviewed the approved ERD and business rules to identify the main screens needed per domain (Warehouse Structure, Inventory, Receiving, Picking/Packing, Adjustment).
- Sketched the screen flow: Login → Dashboard → module list (Warehouses/Locations, Inventory Lookup, Receiving, Picking, Adjustment).
- Designed the layout for the Warehouse & Location management screens (list, tree view by Zone → Aisle → Rack → Bin, create/edit form).
- Defined the shared component set: sidebar navigation, data table with filter/search, status badges, confirmation modal, toast notifications.
- Agreed on the color palette, typography, and spacing scale to keep the UI consistent across screens.
- Collected feedback from the team and adjusted a few screens (moved bulk actions into the table toolbar, simplified the create-location form).
